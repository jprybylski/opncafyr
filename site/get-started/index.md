# Get started

Install opncafyr, open it, and work through a practice study from start to finish.
{: .fs-5 .fw-300 }

{: .research }
> **Research use only.** This workspace has not been validated for clinical or regulatory decisions.

1. [Before you install]({{ '/get-started/before-you-install/' | relative_url }}): what you need, and where opncafyr puts its files.
2. Install on [macOS]({{ '/get-started/install-macos/' | relative_url }}) or [Windows]({{ '/get-started/install-windows/' | relative_url }}) (on a Linux cloud computer, see [the container]({{ '/get-started/install-cloud-container/' | relative_url }}) or [a native install]({{ '/get-started/install-linux/' | relative_url }})). No administrator rights are needed. For a machine without internet access, see [Install from an offline bundle]({{ '/guides/offline-install/' | relative_url }}). To run it on a Linux cloud computer next to your data, see [Run on a cloud computer]({{ '/get-started/install-cloud-container/' | relative_url }}).
3. [Open the app and choose a study folder]({{ '/get-started/first-study/' | relative_url }}).
4. Follow the [two-analyte walkthrough]({{ '/get-started/walkthrough/' | relative_url }}):
   1. [Import and clean]({{ '/get-started/walkthrough-import/' | relative_url }})
   2. [Map and check]({{ '/get-started/walkthrough-map/' | relative_url }})
   3. [Run each analyte]({{ '/get-started/walkthrough-run/' | relative_url }})
   4. [Publish, report and deck]({{ '/get-started/walkthrough-publish/' | relative_url }})

Each page lists the actions in order, what you should see after them, and what to do if something goes wrong.
