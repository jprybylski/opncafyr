                Tutorials

                A tutorial points at each part of the app and tells you what to do there. You do every step yourself: a tutorial never clicks, chooses, runs or publishes anything, and finishing one does not validate an analysis. How to write a tutorial.

                Standards

                Import your team's study standards: study profiles, tutorials, and report and deck templates, from a folder, an archive or a Git repository. Every file is checked against its SHA-256 and you review what changes before anything is installed. Nothing is fetched unless you ask, and a standard never runs an analysis or validates one. About standards bundles.

                Support

                A support bundle helps someone find out why something went wrong. It holds versions, tool health, recent job states and the end of the app's logs. It never holds your data, results or file names, and identifiers, numbers and your user name are masked. You see every part before it is saved, and it stays on this computer.
