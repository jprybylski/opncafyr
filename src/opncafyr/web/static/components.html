Component reference

The shared pieces of the launcher's screens. Guided screens reuse these classes from app.css instead of styling their own. Examples use made-up data.

Buttons

.btn plus .btn-primary, .btn-ghost, .btn-danger, .btn-sm. One primary action per view; danger only for actions that discard work. Links that act as buttons use the same classes.

Status pills

◷ Queued ◔ Preparing ▶ Running ◑ Reviewing ✓ Completed ✓ Recorded ■ Cancelled ! Incomplete ✕ Failed ◌ Checking ✓ Available ✕ Unavailable

Build them with stateBadge(state) from js/dom.js: always a symbol and a word. Tones ok, warn, danger, info mean the same as in the tools under /apps/.
