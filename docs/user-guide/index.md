# opncafyr user guide

> **Research use only.** This workspace has not been validated for clinical or regulatory decisions.

This guide shows how to install opncafyr, set up a study folder, clean and map a concentration file, run one analyte at a time in opnca-r, and turn completed runs into a Word report or a PowerPoint deck. When a report or deck builds without errors, that shows the files were assembled as recorded. It does not show that the analysis is right.

## How the app is laid out

The app opens in your web browser. It and your data stay on the computer that runs it: your own computer, or the cloud computer in [container mode](cloud-container.md). Nothing you load into it is sent anywhere unless you turn on sending in [version history](version-history.md).

- The left side has **Home**, **Data**, **Jobs**, **Analysis**, **Publish**, **Settings**, **Guide**, **Tutorials** and **Standards**, and **Study profile** and **Version history** while a study folder is open. Under **Apps** it lists the tools that have their own screens, such as opnca-r and deckifyr.
- The top bar shows the open study folder, how many jobs are running, a **Theme** button and **Quit**.
- Every page carries the research-use notice.

If you are new to the app, take the **Your first analysis** tutorial (see [Tutorials](tutorials.md)), or start with the [Two-analyte walkthrough](walkthrough.md). It uses a small practice file and takes you from an empty folder to a report and a deck.
